BizLab v0.8 전체 교체 안내

1) GitHub Desktop > Bizlab-cafe > Fetch origin (필요하면 Pull origin)
2) Show in Explorer 열기
3) ZIP 압축 해제 후 내부 파일을 저장소 루트에 모두 복사 / 같은 이름 덮어쓰기
   반드시 app.py, model_v05.py, investment_model.py, data, .streamlit 폴더가 함께 있어야 합니다.
4) 로컬에서 py -m pip install -r requirements.txt
5) 로컬에서 py -m streamlit run app.py
6) 업종 전환 / 고정-변동비 / 초기투자비 / 대출 / 월 PBP / 고급 할인 분석 테스트
7) GitHub Desktop Changes > Commit to main > Push origin
8) https://bizlab-cafe.streamlit.app/ 확인. 실패하면 Streamlit Manage app > Logs 확인

주의: 현재 생성 환경에서는 Streamlit 브라우저 실행 테스트를 수행하지 못했습니다.
