# BizLab v0.8 | 카페 창업 투자 타당성 분석

카페 업종 공식 참고 통계 기반 월 손익 계산기(v0.7) 위에 **초기 투자비·대출상환·사업 전체/자기자본별 PBP·할인 PBP·NPV·월별 현금흐름**을 추가한 Streamlit 프로젝트입니다.

## 실행

```bash
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

Python 설치에 따라 `python -m streamlit run app.py`도 가능합니다.

## v0.8 사용 순서

1. **내 사업 분석**에서 개인 카페/프랜차이즈/전체 업종 평균을 선택하고 고객 수, 객단가, 비용을 조정합니다.
2. **08 초기 투자비**에서 세부 비용을 입력합니다. 초기 입력값은 `0`이며, `예시 투자비로 채우기`는 공식 평균이 **아닌 가상 숫자**입니다.
3. **09 대출**에서 대출 사용 여부, 금액, 금리, 상환기간, 원리금균등/원금균등을 설정합니다.
4. **10 투자금 회수**에서 분석기간, 설비 유지투자, 임대보증금 회수 조건을 설정합니다. 고급 투자분석에서 할인율, 운영자금 회수, 추가 설비투자를 입력할 수 있습니다.
5. **11 시나리오**에서 고객 건수가 변화하면 비용·현금흐름·PBP가 어떻게 달라지는지 확인합니다.
6. 업종 평균과 데이터 출처 원장은 기존 두 탭에 유지됩니다.

## 투자금 및 현금흐름 정의

**금액 단위: 만원.** 투입시점 0개월, 이후 매월 말에 현금흐름이 발생한다고 가정합니다. 최소 기본 분석기간 5년(선택 3/5/7/10년)입니다.

- **총 필요자금 =** 임대보증금 + 권리금 + 공사비 + 설비비 + 가맹비 + 초도 재고/오픈비 + 기타 초기비 + 초기 운영자금. 모든 금액은 사용자가 입력합니다.
- **초기 자기자본 =** 총 필요자금 − 대출 실행금. 대출금액은 총 필요자금을 초과할 수 없습니다.
- **월 운영 현금흐름의 대용치 =** 기존 매출 − 식재료·기타 매출연동비 − 고정 처리 비용(대표자 보상 포함/제외 사용자 선택). **법적·회계적 영업현금흐름이 아닙니다.**
- **사업 전체 CF =** 월 운영 현금흐름 대용치 − 월 유지 설비투자 − 특정 월의 추가 설비투자 + 지정한 월의 보증금 반환 + 지정한 월의 초기 운전자금 반환. 대출금과 원리금상환은 포함하지 않습니다.
- **자기자본 CF =** 사업 전체 CF − 해당 월 대출 이자 − 원금상환. 대출 실행금은 초기 자기자본 계산에서 한 번만 반영합니다.
- **PBP =** 월별 누적 CF가 초기 총 투자액/자기자본 투입액을 **최초로** 회복하는 정수 개월. 분석기간 동안 회복하지 못하면 `분석기간 내 미회수` 표시. 이후 재적자가 발생하는 경우까지 보장하는 지표는 아닙니다.
- **할인 PBP =** 각 월 CF를 월말 현재가치로 할인한 후 같은 방식으로 구한 최초 회수 월.
- **NPV =** −초기 투입금 + 할인된 월별 CF의 합. 사업과 자기자본은 서로 다른 할인율 사용 가능.
- **연 할인율 → 월 할인율 =** `(1 + 연 유효 할인율) ** (1/12) − 1`. **대출 금리 월 이율**은 약정 **연 명목 금리 / 12**로 계산합니다. 대출 금리와 할인율은 같은 개념이 아닙니다.
- **보증금·운전자금 회수:** 기본은 `회수 미반영`이고 사용자가 회수 월과 회수율을 지정하면 그 월에만 유입합니다. 계약 만료 시 무조건 전액 반환한다고 가정하지 않습니다.
- **종료 시 미상환 대출:** 임의로 조기상환시키거나 매각대금으로 상계하지 않습니다. 미상환 잔액을 표시하며 이를 포함해 자기자본 NPV를 해석하는 데 제한이 있음을 안내합니다.

## 회계적 한계 — 꼭 읽어주세요

1. 업종별 원가 기준자료는 농림축산식품부·한국농촌경제연구원의 「2025 외식업체 경영실태 조사」에 수록된 **비알코올 음료점업(5622) 전체**의 2024년 실적 참고값입니다. **커피전문점(56221) 단독 통계가 아니며**, 비용 항목은 공식 분류를 BizLab이 시뮬레이션용으로 변환한 것입니다. 원본 메타데이터는 `data/benchmarks.json`, 출처 선정 근거는 `data/sources.json`을 참고하세요.
2. 업종 평균 식재료비만 매출 연동으로, 나머지 비용은 월 정액으로 가정합니다. 사용자가 기타 운영비 일부를 변동비로 **재분류**하면 같은 금액을 고정비에서 빼 이중 계산을 방지합니다. 이 비중은 공식 통계가 확인한 비중이 아닙니다.
3. 월 운영 현금흐름은 이익에서 출발한 **대용치**입니다. 영업이익과 영업현금흐름이 같지 않을 수 있습니다. 실제 감가상각, 재고·매입채무·운전자금 변동, 부가세 정산, 소득세, 법인세, 대출이자 손금 효과, 매출 안정화 램프업, 철거·원상복구·매각가격은 정확히 추정하지 못합니다. 임의로 비현금성 비용을 가산하거나 근거 없는 세금 수치를 만들지 않았습니다.
4. 대표자 보상을 포함할지 선택할 수 있습니다. 제외하면 노동의 기회비용을 계산하지 않는 것이므로 해석 시 유의하세요.
5. 월 유지 설비투자와 기존 `기타 운영비`가 겹치지 않도록 사용자가 확인해야 합니다. `초도 재고`와 `초기 운전자금`의 중복도 주의하세요.
6. 모든 금액은 **부가가치세 포함/제외 기준을 사용자 스스로 통일**해야 합니다. 자동 세금 계산기가 아닙니다.
7. 할인 PBP와 NPV는 **투입한 할인율·사업기간·비용 가정에 민감**합니다. 비교용 지표이지 사업 성공을 보장하지 않습니다.

## 초기 투자비 출처 상태

**초기 투자비의 업종 공통 공식 평균은 현재 확정하지 않았습니다.** 특히 프랜차이즈는 브랜드별 가맹사업 정보공개서에서 가맹점주가 부담하는 창업비용 등을 확인할 수 있으나, 보증금·권리금·점포별 공사비까지 동일한 범위로 묶은 전국 공통 실제 초기 투자비로 취급할 수 없습니다.

- 경기도 가맹정보제공시스템(정보공개서 설명): https://fair.gg.go.kr/board/infoOpenReg/infoOpenReg.do
- 공정위 가맹사업정보공개시스템: https://franchise.ftc.go.kr/
- 사용자의 구체적 가맹 브랜드·입지·점포 면적을 알기 전에는 브랜드별 초기비용을 자동 채택하지 않습니다.

**검증하지 못한 항목:** 이 생성 환경에는 Streamlit 및 pandas가 설치되지 않았고 패키지 저장소 접속이 불가능해 실제 Streamlit 브라우저 렌더링·모바일 반응형 테스트·Streamlit Cloud 배포는 실행하지 못했습니다. 따라서 **GitHub 배포 전 로컬 실행 확인이 필수**입니다.

## GitHub Desktop에서 전체 교체

1. GitHub Desktop에서 `Bizlab-cafe`의 **Fetch origin**을 누르고 `Pull origin`이 나타나면 먼저 받으세요.
2. 이 ZIP을 풀고 **ZIP 내부 파일들**(`app.py`, `model_v05.py`, `investment_model.py`, `data/`, `.streamlit/`, `test_*.py` 등)을 GitHub Desktop의 `Show in Explorer`에서 열리는 **저장소 최상위 폴더에 바로** 복사해 덮어씁니다. ZIP 상위 디렉터리를 한 겹 더 만들면 안 됩니다.
3. 변경 목록에서 **`app.py`, `investment_model.py`, `test_investment_model.py`** 등이 함께 표시되는지 확인합니다.
4. PC에서 `py -m streamlit run app.py`를 실행하여 초기 화면·투자비 입력·대출 토글·할인 결과·시나리오를 확인합니다.
5. GitHub Desktop `Summary`에 `BizLab v0.8 investment analysis` 입력 → **Commit to main** → **Push origin**.
6. https://bizlab-cafe.streamlit.app/ 에서 `Ctrl+Shift+R`로 새로고침합니다. 오류가 있다면 Manage app → Logs의 전체 traceback을 확인합니다.
